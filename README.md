This project was done out of interest in estimating a factor-driven mortality hazard function for use in a customizable portfolio that mimics the rebalancing of a common target date fund (TDF). It's feature set and methodology mimic the paper by Puterman et al. and uses the [MIDUS](https://midus.wisc.edu/) demographic survey data.

The survival curve output by the personal mortality prediction model may be used in the Retirement or Ruin repository to assist in the discovery of an optimal glide path.
